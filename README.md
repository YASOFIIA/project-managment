# Project Management Service

> Work in progress. This README is replaced with real documentation in task T6.4.

## How to start working (Antigravity)

1. Put this folder in a new git repository and open it in Antigravity.
2. Put the mentor's example project **outside** this folder (it is a read-only reference).
3. Open `PROMPTS.md`, copy prompt **0** and send it to the agent.
4. Then go through `PLAN.md` one task at a time using prompt 1 from `PROMPTS.md`.

## Files

| File | Purpose |
|---|---|
| `TASK.md` | Original requirements (source of truth) |
| `AGENTS.md` | Rules for the coding agent (stack, conventions, teaching mode) |
| `PLAN.md` | Tasks by phase, agent builds, user reviews, definition of done |
| `PROMPTS.md` | Ready-to-paste prompts |
| `REFERENCE_NOTES.md` | Which files of the example project are worth reading |
| `docs/OPEN_QUESTIONS.md` | Questions for the mentor + defaults |
| `docs/LEARNING_LOG.md` | Your notes per task (for the defense) |
